# Задание 1. Инвентарь персонажа

Курс «Python 2», занятие 9 (тесты). Задание сдаётся через git: вы пишете код в своём репозитории, отправляете его на GitHub, и тесты проверяют решение автоматически.

## Что нужно сделать

В файле `src/inventory.py` дописать методы класса `Inventory`. Сейчас все методы — заглушки с `raise NotImplementedError`.

| Метод | Что делает |
|---|---|
| `add(name, count=1)` | добавляет предмет. Если `count` меньше 1, выбрасывает `ValueError` |
| `remove(name, count=1)` | убирает предмет. Если предмета нет или его меньше, чем нужно, выбрасывает `ValueError`. Если стало 0, предмет удаляется |
| `count(name)` | количество предмета, 0 если предмета нет |
| `total()` | сумма количеств всех предметов |
| `to_dict()` | копия словаря предметов (изменение копии не меняет инвентарь) |
| `save(path)` | записывает инвентарь в JSON-файл |
| `load(path)` | читает JSON-файл и возвращает новый `Inventory` |

Все тесты лежат в `tests/test_inventory.py`. Их читать обязательно: там видно, что ожидается.

## Как запустить тесты у себя

```bash
pip install -r requirements.txt
python -m pytest -v
```

Пока методы не написаны, тесты падают. Это нормально. Цель — сделать все тесты зелёными.

## Как сдать

0. Нажимаете «Use this template» на странице репозитория — появится ваш репозиторий с заданием.

1. Пишете код в `src/inventory.py`.
2. Проверяете тесты локально.
3. Сохраняете изменения:
   ```bash
   git add src/inventory.py
   git commit -m "Инвентарь: все методы"
   git push
   ```
4. Открываете вкладку **Actions** на GitHub: там видно, какие тесты прошли и какие упали.

## Критерии

- все методы работают по описанию в таблице;
- ошибки выбрасываются там, где написано;
- код читается: имена понятные, нет повторов.
